# Inktoberfest 2026 · Skillbox Community

Онлайн-выставка студенческих работ: цифровой дизайн, AI-креаторы, 2D и 3D художники.

360 изображений, 34 автора. Фильтры по направлениям и темам, поиск автора, просмотр работ.

## Локальный запуск

```sh
python3 -m http.server 4173
```

Открыть http://127.0.0.1:4173/. Сборка и установка зависимостей не требуются.

## Авторство

Работы принадлежат указанным в галерее авторам. Наличие файлов в репозитории не предоставляет разрешения на их повторное использование.
